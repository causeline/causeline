Six things Causeline does while you click through your app.

1 / 6

  • One timeline, any stack

    The click, fetch, controllers, services, repositories, every SQL statement with its real values, transactions, logs, messages and the re-render. Spring MVC or WebFlux, JDBC or R2DBC, React or Next.js.

  • Find what’s slow

    The bottleneck is ranked by self time, so a slow parent never hides the real culprit. N+1 queries come with the fix to try, and transactions held open during an HTTP call are flagged.

  • See where it broke

    The file and line in your code that threw, one click from VS Code, IntelliJ IDEA or Cursor. Exceptions your code catches and only logs show up too.

  • Replay and compare

    Send a captured request again to local, dev or QA with that environment’s credentials, then compare the two runs span by span, response bodies included.

  • Prove the fix

    Run EXPLAIN on a captured query, check a response against your OpenAPI document, then copy the request as a test. @CauselineTest checks query count, N+1 and failures on every build.

  • Local first

    Runs inside your app at /causeline. No account, agent or cloud. Off by default, refuses to start in production, and redacts everything it exports, including OTLP.

Why I built it

Every slow checkout I chased began the same way: five tools open, and none of them talking to each other.

  • Browser Network tabrequest timing
  • React DevToolsstate and renders
  • Spring Boot logsgrep by timestamp
  • A debuggerone breakpoint at a time
  • Postmanreplay, by hand
  • Causelineone trace, every layer

The Network tab said the request took a second. React DevTools showed the re-render. The Spring logs had a timestamp I had to line up by hand. The debugger stopped one thread at a time, and Postman replayed the request without the cookie that made it fail.

Each tool told the truth about one layer. None of them could tell me which layer was the cause.

So I built the view I kept wishing for: the click, the request, every query and outbound call, and the re-render, on one timeline, inside the app I was already running. No account, no agent, nothing sent anywhere.

Causeline is free, open source and still young. If it saves you an afternoon, or if it breaks, I would like to hear about it.
